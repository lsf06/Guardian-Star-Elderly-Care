# 演示素材

放**不需要硬件就能跑出**的东西。有人 clone 下来 30 秒内能看懂你在干什么。

## 要放什么

| 文件 | 怎么来 | 时长 |
|---|---|---|
| `mock_run.mp4` / `.gif` | `Win + G` 对着屏幕录 `python src/mock_run.py` | 25 秒 |

录这六行覆盖的整段（脚本的真实输出，[docs/11月展示冲刺执行手册.md](../docs/11月展示冲刺执行手册.md) 1.2 节）：

```text
[0005] startup    启动 5 秒仍未检测到人，请检查摆放位置与雷达朝向
[0096] ask        奶奶，有一阵子没看到您了，您还好吗？
[0100] ask_again  我有点担心，您按一下手边的键好吗？
[0101] resolved   好的，您没事就好。
[0224] escalate   老人较长时间未活动且未回应问候，建议致电确认。
[0620] chat       （未配置 DEEPSEEK_API_KEY）我在呢，您慢慢说。
```

**这六行连起来才是完整闭环**：问 → 补问 → 答 → 再问 → 推送 → 陪聊。
只录 ask / resolved 两行，观众看不出「问没答就升级」这个关键设计。

## 录屏注意事项

1. 终端字号调大（至少 16 号），手机横屏拍，不要竖屏。
2. 关掉通知、关掉别的人窗口，画面里只留终端。
3. 顺手把 `python src/selftest.py` 的输出也录 3 秒——评委问「解析对不对」时直接放。
4. 文件名用英文，避免在 GitHub 上预览出问题。

## 不要放什么

- 合成数据跑出来的漂亮曲线（`data/_synthetic_*`）。它不是实测，放进演示等于自己埋雷。
- 还没接硬件的「效果图」「概念图」。仓库里已经有 `hardware/wiring.svg` 和 `docs/figs/` 两张真图，够了。
