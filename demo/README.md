# 演示素材

放**不需要硬件就能跑出**的东西。有人 clone 下来 30 秒内能看懂你在干什么。

## 要放什么

| 文件 | 怎么来 | 时长 |
|---|---|---|
| `mock_run.mp4` / `.gif` | 手机对着屏幕录 `python src/mock_run.py` | 10 秒 |

建议只录这两行，其余剪掉：

```
[0096] ask        奶奶，有一阵子没看到您了，您还好吗？
[0101] resolved   好的，您没事就好。
```

**这两行是整段演示的全部意义**：设备先开口问，老人按键，事件结束。
四秒之内，一个不懂技术的人也能看懂这个项目在做什么。

## 录屏注意事项

1. 终端字号调大（至少 16 号），手机横屏拍，不要竖屏。
2. 关掉通知、关掉别的人窗口，画面里只留终端。
3. 顺手把 `python src/selftest.py` 的输出也录 3 秒——评委问「解析对不对」时直接放。
4. 文件名用英文，避免在 GitHub 上预览出问题。

## 不要放什么

- 合成数据跑出来的漂亮曲线（`data/_synthetic_*`）。它不是实测，放进演示等于自己埋雷。
- 还没接硬件的「效果图」「概念图」。仓库里已经有 `hardware/wiring.svg` 和 `docs/figs/` 两张真图，够了。
