# 调研数据目录

这个目录由 `tools/crawl_market.py` 生成，**只抓公开页面，只读**。

## 文件

| 文件 | 内容 | 怎么用 |
|---|---|---|
| `ccgp_YYYYMMDD.csv` | 政采公告列表里命中关键词的条目 | 看有多少地方在买这类东西 |
| `ccgp_detail.csv` | 打开过正文的公告，含预算金额与中标方 | **真实成交价，最有价值** |
| `policy_YYYYMMDD.md` | 政策原句摘录 | 引数据用，引前必须回原文核对 |

## 三条使用纪律

1. **金额必须回原文核对**。正则抽的是「预算金额：」后面第一个数字，
   可能抽到分包价、也可能抽到整个项目的总预算（含土建）。
2. **不要把这些数字直接当市场规模的证据**。它们是「已发生的采购」，
   不是「全部需求」。只能说「这个价位有人真的在买」。
3. **不抓个人隐私、不抓社交平台**。知乎/小红书/微博都有反爬，
   绕过属于对抗行为，本脚本故意不做。要用户原话只能自己去访谈。
