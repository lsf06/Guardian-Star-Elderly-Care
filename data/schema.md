# 数据字典

每一行 = 一个时间点的雷达状态。**缺少 `session` 和 `label`，两周后你的数据就没法分析了。**

```csv
session,t,label,phase,state,door,move_dist,still_dist,still_energy,event_at
s01_20261101,0.0,empty,pre,0,0,0,0,3,
s01_20261101,0.1,empty,pre,0,0,0,0,2,
s02_20261101,0.0,sit,pre,2,0,0,152,48,
s03_20261101,19.8,breathhold,pre,2,0,0,150,46,20
s03_20261101,34.6,breathhold,event,0,0,0,0,4,20
```

## 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `session` | string | 是 | 一次采集的唯一标识，建议 `标签_日期_序号` |
| `t` | float | 是 | 相对本次采集开始的秒数 |
| `label` | enum | 是 | 见下表 |
| `phase` | enum | 是 | `pre` / `event`，事件发生前后。**这一列决定了你能不能算延迟** |
| `state` | int | 是 | 0 无人 / 1 运动 / 2 静止 / 3 运动+静止 |
| `door` | int | 是 | 0 关门 / 1 开门。**这一列决定了能不能验证门磁否决** |
| `move_dist` | int | 是 | cm，无目标时为 0 |
| `still_dist` | int | 是 | cm |
| `still_energy` | int | 是 | 0–100，静止目标能量 |
| `event_at` | float | 事件组必填 | 你在第几秒做的动作（屏息 / 躺倒 / 开门）。**填错这一列，延迟全废** |

## label 取值

| label | 怎么做 | 用来算什么 |
|---|---|---|
| `empty` | 人离开房间，只留设备 | 底噪。没有它定不了任何阈值 |
| `sit` | 正常坐着看电视 / 玩手机，3–10 分钟 | 静坐误问候率 |
| `moving` | 在房间里走动 | 运动误判检查 |
| `breathhold` | 第 20 秒起屏息不动，能屏多久屏多久 | **核心实验**：屏息时雷达是否会丢目标、延迟多久 |
| `lie` | 第 20 秒躺到地上，不动，但**正常呼吸** | 关键负结果：证明"不做跌倒检测"这个边界 |
| `exit` | 第 20 秒起身开门离开 | 门磁否决是否生效（误问候必须为 0） |

## 三条纪律

1. **不要只保存成功的数据。** 采不到、抖动大的样本，恰恰是最有价值的部分——所有人都只报成功数据。
2. **每次采集前重录一次 `empty`。** 房间布局、家具移动、Wi-Fi 路由器位置都会改变底噪。
3. **`label` 与 `event_at` 在采集开始时就要写进命令行**，不要事后补。事后补的一定错。
