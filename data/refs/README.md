```bash
workbuddy-pdf "LD2410C_串口协议_V1.09.pdf" proto.txt --format txt
```

## 这两份文档推翻过我两处说法

1. **工程模式门能量偏移**：payload[11]=最大运动门、[12]=最大静止门，
   门能量从 [13] 起。旧代码从帧尾反推、漏扣「光敏+OUT」两字节，
   导致整段门能量错位。详见 `docs/与官方文档核对_协议与参数.md`。
2. **G0/G1 没有被出厂关闭**：读取参数 ACK 里九个门的静止灵敏度全是 25，
   关闭是设为 100 而不是 0；探测距离下限是 0.75 m 而不是 1.5 m。
