# 语音素材

这个目录里必须放五个 WAV，否则设备**一句都不会出声**。

`src/voice.py` 的安全路径是 `strict=True`：本地文件缺失时它不会偷偷联网合成，
只会打印一行 `[!!] 安全语音缺失`。这是故意的——用云 TTS 播报安全提示，
等于把「老人有没有被问到」交给网络，而断网正是你写在边界里的失效条件。

## 要录的五句

| 文件名 | 内容 | 什么时候播 |
|---|---|---|
| `ask.wav` | 奶奶，有一阵子没看到您了，您还好吗？ | 静默超阈值，第一次问候 |
| `ask_again.wav` | 您还好吗？拍拍这个按钮就行。 | 二次问候（可选） |
| `resolved.wav` | 好的，您没事就好。 | 老人按键消解 |
| `fault.wav` | 我这边的雷达好像没连上，请看一下线。 | 心跳超时 |
| `sos.wav` | 紧急求助！请帮帮这位老人，请帮忙拨打 120 或联系家属！ | 按下红键 |

`away.wav`（您要出门呀？路上慢点）可选，代码不强制。

## 怎么录

1. 手机自带录音机，安静房间，离嘴 20 cm，**语速比平时慢三分之一**。
2. 导出后转成 **16 kHz、单声道、16 bit PCM** 的 WAV：

```bash
ffmpeg -i 手机录音.m4a -ar 16000 -ac 1 -c:a pcm_s16le ask.wav
```

3. 放进本目录，确认文件名完全一致（区分大小写）。

验证：

```bash
python -c "import sys; sys.path.insert(0,'src'); import voice; print(voice.speak('x','ask',strict=True))"
```

打印 `local` 就对了；打印 `missing` 说明文件名或路径不对。
树莓派上还需要 `sudo apt install alsa-utils`（提供 `aplay`）。

## 为什么不用 TTS

树莓派上的 espeak 是机械音，老人听不清；在线 TTS 断网就哑。
真人录音零延迟、断网可用，而且——这是唯一能让老人觉得「这台机器在跟我说话」而不是「在播报」的方式。

## 先跑通再换真人

快递还没到、想先看效果，可以用一次性生成：

```bash
pip install edge-tts
python tools/make_audio.py
```

它会把五句合成到本目录。**能出声就够了，但答辩前请换成真人录音**：
机器音会让「有温度的问候」这个卖点当场失效。
