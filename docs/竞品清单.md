> 价格均为公开可查的电商页面价或政府采购中标价，采集时间 2026-11，会波动，只作量级参照。

## 二、我们和谁比、不比什么

**不比识别率。** 970 元的机器在跌倒识别上一定比我们强，我们没有姿态模型，也不打算有。
**不比覆盖。** 一台守一个房间，这是明确边界，全屋是 v2 的事。

**只比一件事：报警之前，有没有人先问老人一句。**

```
它们：  检测到异常 ──────────────────────→ 直接推手机
我们：  检测到异常 → 语音问一句 → 等 30 s → 没人应 → 推手机
                                  ↑
                          老人按一下，这一次就不打扰子女
```

这一步不值钱——一个按键、一段录音、一个定时器。
但它决定了这台设备**会不会在一个月内被静音或被拔掉**。

## 三、三句话讲完差异（照着说）

1. **"市面上 150 元的白牌雷达只报'有人没人'，799 元的萤石能识别跌倒，970 元的清雷进的是政府招标。"**
2. **"它们都缺同一步：报警之前不问老人。所以它们的误报直接落在子女手机上，一个月后就被静音。"**
3. **"我做的不是更准的雷达，是那一步确认。硬件成本没增加，增加的是一个按键和一套状态机。"**

| 追问 | 答法 |

| "你的数据来源可靠吗？" | "中标价来自政府采购结果公告（2026-09 东莞安居、2026-08 什邡民政），电商价来自公开页面，都标了时间。会波动，所以我只说量级。" |
