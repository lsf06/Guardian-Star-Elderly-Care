## 2. 静坐 `sit` —— 算「正常生活会不会被误问候」

```bash

```

坐姿要**接近真实**：看电视、低头玩手机、打盹。**不要刻意坐直不动**，那样测出来的是实验室，不是家里。

| 轮次 | 姿态 | 是否背对雷达 | 是否打盹 | 异常 | 采用 |
|---|---|---|---|---|---|
| 1 | 正对 / 侧身 / 背对 | | | | |
| 2 | 正对 / 侧身 / 背对 | | | | |
| 3（可选，背对加测） | | 是 | | | |

> **背对那一轮特别重要**：它会成为你边界声明里"背对时感应下降"的唯一实测依据。

## 3. 屏息 `breathhold` —— 核心实验，决定项目天花板

```bash
python src/capture.py --label breathhold --minutes 3 --event-at 20
```

流程：先正常坐 20 秒 → 第 20 秒开始屏息、完全不动 → 屏到极限（难受就停，别硬撑）→ 记下你实际屏了多少秒。

| 轮次 | 实际屏息秒数 | 屏息期间雷达是否仍报"静止" | 是否触发问候 | 触发时刻 | 异常 |
|---|---|---|---|---|---|
| 1 | ______ s | 是 / 否 | 是 / 否 | ______ s | |
| 2 | ______ s | 是 / 否 | 是 / 否 | ______ s | |
| 3 | ______ s | 是 / 否 | 是 / 否 | ______ s | |

> **这一组的解读方式（写报告时直接用）：**
> - 屏息 30 秒内就丢目标 → 雷达靠的是呼吸微动，**真实衰弱老人呼吸浅，风险高**，必须在报告里写清楚适用人群。
> - 屏息 60 秒以上仍锁定 → 雷达靠的是更粗的微动/体表反射，**结论比你预期的更好**，检测不依赖呼吸。
> 两种结果都能用，**但你必须知道是哪一种**。

## 4. 躺平 `lie` —— 关键负结果，用来证明"我不做跌倒"

```bash
python src/capture.py --label lie --minutes 3 --event-at 20
```

第 20 秒躺到地上，**正常呼吸、不动**。

| 轮次 | 躺的位置（离雷达多远） | 雷达是否仍看到"静止" | 是否触发问候 | 异常 |
|---|---|---|---|---|
| 1 | ______ m | 是 / 否 | 是 / 否 | |
| 2 | ______ m | 是 / 否 | 是 / 否 | |

> 如果结果是"仍能看到"——**这是好消息，不是坏消息**。它正好证明：倒在地上但还在呼吸的人，本设备**不会**误判为异常静默，所以它真的不是跌倒检测器，边界声明第 1 条是有实测支撑的。

## 5. 开门离场 `exit` —— 验证门磁一票否决


第 20 秒起身、开门、走出去、关门，**在门外待满剩下的时间**。

| 轮次 | 门磁读数（开=1 / 关=0）是否正常 | 离场期间是否触发问候 | 异常 |
|---|---|---|---|
| 1 | 是 / 否 | **必须是"否"** | |
| 2 | 是 / 否 | **必须是"否"** | |

> 这一组只要出现 1 次误问候，你的「门磁否决」卖点就当场破了。**先修这条，再谈别的指标。**

## 7. 时间预算（一次做完，别拆成好几天）

| 步骤 | 实际耗时 |
|---|---|
| 接线 + `test_radar.py` 调通 | 30–60 min（第一次会卡在串口权限 / 波特率） |
| 摆放距离测试 0.8 / 2.4 / 3.8 m × 60 s | 10 min |
| 五组采集，每组 2 轮 | 60–80 min |
| `sweep.py` + 填表 | 15 min |
| **合计** | **约 2–2.5 小时** |

> 建议一次做完。**跨天采的数据，房间布局、家具位置、甚至路由器位置都变了，底噪不可比。**
