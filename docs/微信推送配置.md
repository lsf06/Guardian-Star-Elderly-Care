# 家属通知：五条路，怎么选

> 目标：**家属不用装你写的 App**，微信里能收到。老人侧仍然只有一个动作——拍按钮。
> 代码在 `src/voice.py` 的 `push_family()`，按环境变量自动选通道，配几个发几个。

---

## 一、先看这张表，按你的场景选一行

| 你的场景 | 用哪条 | 为什么 |
|---|---|---|
| **自己演示 / 答辩** | 企业微信群机器人 | 0 成本、5 分钟配好、群里只有自己，不受外部群限制 |
| **自家或 1–3 户试点** | 企业微信群机器人 | 家属加成企业成员即可，用个人微信收 |
| **要卖给陌生家庭** | **WxPusher**（首选）或 PushPlus | 扫码即用，不需要把别人拉进你的企业 |
| **只要验证「链路通没通」** | Server酱 | 5 条/天够测试，但不够日常 |
| **一条都不配** | 只打印 `[PUSH]` | 不会假装送到 |

## 二、五条通道的全部限制（2026-11 查官方文档）

| 通道 | 环境变量 | 频率 / 额度 | 家属要做什么 | 适合对外卖？ |
|---|---|---|---|---|
| 企业微信群机器人 | `WECOM_WEBHOOK` | **20 条/分钟**，官方**未公布日上限** | 装企业微信，**或被加进企业通讯录**后用个人微信关注「微信插件」 | ❌ 进不了外部群 |
| PushPlus | `PUSHPLUS_TOKEN` | 200 条/天，同内容 1 小时 3 条 | 关注公众号 | ✅ 但**必须实名** |
| **WxPusher（极简）** | `WXPUSHER_SPT` | 免费，约 2 QPS；单日超 3000 条才限流 | **扫码一次**即可 | ✅ **最省事** |
| WxPusher（标准） | `WXPUSHER_APPTOKEN` + `WXPUSHER_UID` | 同上，单次最多 2000 个 UID | 扫码绑定 | ✅ 多家属时用 |
| Server酱 | `SERVERCHAN_SENDKEY` | **免费 5 条/天**，50 条/分钟 | 扫码关注 | ⚠️ 额度太小 |

### 四种平台的「成功码」各不相同 —— 这是最容易写错的地方

| 平台 | 判定成功的字段 | 值 |
|---|---|---|
| 企业微信群机器人 | `errcode` | **0** |
| PushPlus | `code` | **200** |
| WxPusher | `code` | **1000** |
| Server酱 | `code` | **0** |

四个数字、三个字段名。写错一个，就会把「失败」记成「已送达」——而这条路径上的下一次调用，可能是老人按了红键。代码里四个分支各自校验，不要合并。

## 三、企业微信群机器人（自用 / 试点）

### ⚠ 先说这条限制：进不了外部群

官方帮助文档原文：

> **目前内部群聊支持消息推送，外部群暂不支持。**
> 群聊有非内部员工就是外部群。

所以**家属必须是你的「企业成员」**，否则拉不进能加机器人的群。

### 1. 建群、加机器人

1. 手机装企业微信（注册时企业名可随便填，个人也能注册，**不需要营业执照**）
2. 建一个**内部群**（成员必须都是企业成员）
3. 群右上角「…」→「群机器人」（新版叫「消息推送」）→「添加机器人」
4. 复制生成的 Webhook：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```

> **企业认证**：官方帮助未明文要求，但第三方教程普遍提到「企业需完成验证/认证」。
> 建议**先花 5 分钟试一次**，加不上就认证或改用 WxPusher，不要卡在这里。

### 2. 家属用个人微信收（五步，缺一不可）

1. 管理后台 →「通讯录」→「添加成员」→ 填家属手机号
2. 管理后台 →「我的企业」→「微信插件」→ 复制邀请二维码（**有效期仅 7 天**）
3. 家属用**个人微信**扫码关注
4. 微信里打开「接收企业消息」+「置顶聊天」
5. 把家属拉进那个有机器人的内部群

之后机器人消息直接弹在他个人微信里，**不用装企业微信 App**。

## 四、WxPusher（对外卖首选）

比 PushPlus 省事：**不用注册应用、不用实名、扫码就有一个 SPT**。

### 极简模式（推荐，30 秒）

1. 打开 <https://wxpusher.zjiecode.com>
2. 微信扫码登录
3. 「我的」→ 找到 **SPT**（形如 `SPT_xxxxxxxx`）→ 复制
4. 配到设备上：

```bash
export WXPUSHER_SPT="SPT_你的值"
python -c "import sys; sys.path.insert(0,'src'); import voice; print(voice.push_family('通道测试'))"
```

返回 `True` 就是发出去了。

**限制**：内容放在 URL 里，长消息会被截断。本项目推送都在 100 字内，不受影响。

### 标准模式（多家属、长消息）

1. 「应用管理」→ 创建应用 → 拿 `AppToken`（`AT_xxx`）
2. 「用户管理」→ 看到 `UID`（`UID_xxx`）；多个家属用逗号分隔
3. 配两个环境变量：

```bash
export WXPUSHER_APPTOKEN="AT_你的token"
export WXPUSHER_UID="UID_家属1,UID_家属2"
```

### 要提醒家属的一件事

WxPusher 有个**微信 ClawBot 渠道**，如果家属绑了那个渠道，**24 小时内最多收 10 条**，用完后要向 ClawBot 回一条消息才能继续收。对这台设备（日均不到 10 条）够用，但要在说明书里提一句，否则家属某天收不到会以为设备坏了。

## 五、PushPlus（备选，必须实名）

1. 微信打开 <https://www.pushplus.plus> 扫码登录
2. **先实名**（`verify.pushplus.plus`），不实名调接口返回 `code: 905`
3. 「一对一推送」页面复制 Token
4. `export PUSHPLUS_TOKEN="你的token"`

已知错误码（**都会返回 HTTP 200**，所以代码校验业务码）：

| code | 原因 |
|---|---|
| 905 | 未实名 |
| 903 | token 无效 |
| 900 | 当日超 200 条 / 同内容 1 小时内超 3 条 |

最后一条对这套设备不构成问题：**同一次静默只推 1 次**。

## 六、Server酱（只够验证链路）

1. <https://sct.ftqq.com> 微信扫码
2. 复制 SendKey（`SCT` 开头）
3. `export SERVERCHAN_SENDKEY="你的key"`

**免费只有 5 条/天。** 够你做一次「链路通没通」的验证，不够日常跑。要在试点用，得订阅（约 3–8 元/月）。

## 七、一条命令验证任意通道

```bash
cd guardian
export WXPUSHER_SPT="SPT_xxx"
python -c "import sys; sys.path.insert(0,'src'); import voice; print(voice.push_family('通道测试，收到请忽略'))"
```

- `True` → 去看微信，收到就通了
- `False` → 看终端打印的具体错误（`errcode` / `code` 加原因）

代码会**同时尝试所有已配置的通道**，任一成功即返回 `True`，全部失败才写 `data/_push_failed.jsonl`（记录里带每个通道各自的原因）。

## 八、密钥不能进仓库

所有通道的凭据都是「谁拿到谁能发消息」：

- 只从环境变量读，代码里不写死
- 不截图进 PPT、文档、issue
- 企业微信 webhook 泄露了 → 群里删掉机器人重建
- WxPusher SPT 泄露了 → 重新扫码拿新的
- PushPlus token 泄露了 → 后台重置

`.gitignore` 已忽略 `data/_push_failed.jsonl`（里面可能带消息正文）。环境变量本身不在仓库里，天然安全。

## 九、这条链路的真实边界（答辩必须说）

| 能做到 | 做不到 |
|---|---|
| 老人不回应时，微信收到一条消息 | **确认家属已读**。四个平台都只回「已受理」，没有已读回执 |
| 每次事件只推 1 条，不会刷屏 | 断网时推送失败，只落盘，**没有自动补发** |
| 同时配多条通道互为备份 | 家属不回消息，设备不知道 |

> 「当天就知道设备被拔了」的成立前提是：**配了通道、家属每天确实收到一条、且知道每天都该有一条**。
> 断电的设备发不出自己的死讯——这是使用约定，不是设备能力。

## 十、更重但更正规的三条路（本期不做）

| 方案 | 门槛 | 说明 |
|---|---|---|
| 微信服务号 + 模板消息 | **企业主体 + 300 元/年认证** | 个人订阅号**根本没有模板消息权限**。模板文案固定不可改，只能填参数 |
| 微信小程序 | 需注册 + 审核 | 扫码即用、不上架商店。三个页面足够，约 2–3 天 |
| 自建企业微信应用（Wecom酱） | 需可信 IP、云函数 | 官方开源方案，能推到个人微信，但要部署和维护 |

**为什么本期都不做**：现在的缺口是「设备还没有真实数据」，不是「通知送达得不够花哨」。等有试点合同、有认证需求了再谈。
