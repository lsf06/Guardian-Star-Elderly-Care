# 家属通知：怎么接到微信上

> 目标：**家属不用装任何 App**，微信里就能收到。老人侧仍然只有一个动作——拍按钮。

---

## 一、两条通道，按这个优先级配

| 通道 | 免费额度 | 家属要装什么 | 建议 |
|---|---|---|---|
| **企业微信群机器人**（`WECOM_WEBHOOK`） | 免费，**20 条/分钟**；官方未公布日上限 | **必须是企业成员**：装企业微信，或用个人微信关注「微信插件」接收 | 自用 / 试点首选 |
| PushPlus（`PUSHPLUS_TOKEN`） | 200 条/天，同内容 1 小时最多 3 条 | 关注一个公众号（任何微信都行） | **陌生人场景唯一可行** |

两个都配就都发（报警场景宁可重复一条）。只配一个也能跑。都没配就只在日志里打印 `[PUSH]`，**不会假装送到**。

代码在 `src/voice.py` 的 `push_family()`，自动按环境变量选通道。

---

## ⚠ 一条必须先说清的限制：群机器人进不了「外部群」

企业微信官方文档写得很明确：

> **目前内部群聊支持消息推送，外部群暂不支持。**（[官方帮助](https://open.work.weixin.qq.com/help2/pc/14931)）
> 群聊有非内部员工就是外部群。

这意味着：**如果家属不是你这个「企业」的成员，你根本没法把他拉进能加机器人的群。**

所以这条通道的真实适用范围是：

| 场景 | 能用群机器人吗 | 怎么做 |
|---|---|---|
| 你自己演示（群里只有你一个成员） | ✅ 能 | 建内部群，拉自己 |
| 家属用个人微信关注「微信插件」 | ✅ 能，**前提是家属被加进企业通讯录** | 见第 3 步，这一步要理解清楚 |
| 卖给陌生家庭 | ❌ **不能** | 必须换 PushPlus，或做真正的 App / 小程序 |

**「家属用个人微信就能收」这句话有前提**：家属得先作为**企业成员**被加进来（管理后台 → 通讯录 → 添加成员，填他的手机号），他再用个人微信扫码关注「微信插件」。此时他既是「企业成员」，又只在个人微信里收发消息——**不用装企业微信 App，但需要被加进你的企业**。

对课程项目 / 自家试点，这完全可行（加 1–3 个人而已）。对「卖给一百个陌生家庭」，这条路走不通——那才是 PushPlus 或小程序的位置。

## 二、企业微信群机器人（自用 / 试点）

### 1. 建群、加机器人

1. 手机装**企业微信**（注册时企业名可随便填，个人也能注册，**不需要营业执照**；
   但注意：未认证企业**能否加群机器人存在变数**，见本节末尾）
2. 建一个**内部群**（群成员必须都是企业成员，不能拉外部微信好友）
3. 群右上角「…」→「群机器人」（新版叫「消息推送」）→「添加机器人」
4. 起个名（比如「守护星」），创建后会给你一串 Webhook 地址：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```

> **官方口径核对（2026-11 查）**：帮助文档只写了「内部群支持、外部群不支持」，
> 以及「管理员可在后台设置可创建机器人的成员范围」。**没有明文要求企业认证**，
> 但第三方服务商的教程普遍提到「企业需完成验证/认证才可使用群机器人」。
> 我的建议：**先按第 2 步花 5 分钟试一次**，能加上就说明你的号可以；
> 加不上就去认证，或直接改用 PushPlus——不要在这上面卡住。

### 2. 配到树莓派上

```bash
export WECOM_WEBHOOK="https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key"
python src/guardian_main.py --port /dev/ttyAMA0 --pin-door 18 --pin-button 17
```

要开机自动生效，写进 `~/.bashrc` 或 systemd 的 `Environment=`。**不要写进仓库里的任何文件**——见第五节。

### 3. 家属怎么用个人微信收（有前提）

完整步骤，缺一步都收不到：

1. **先把家属加进企业通讯录**：管理后台（work.weixin.qq.com）→「通讯录」→「添加成员」→ 填他的手机号
2. 管理后台 →「我的企业」→「微信插件」→ 复制「邀请关注」的**二维码**
   （注意：这个二维码**有效期只有 7 天**，过期要重新生成）
3. 家属用**个人微信**扫这个码关注
4. 关注后，在微信「通讯录 → 我的企业」里能看到，并要**打开「接收企业消息」和「置顶聊天」**
5. 把他也拉进那个有机器人的内部群

之后机器人发的消息，会在他的个人微信里弹出来，**不用装企业微信 App**。

**限制（官方明确）**：

- 微信插件**只对「企业成员」开放**，不是企业成员扫不了码
- 全员群超过 2000 人时，消息不同步到微信插件（对本项目无影响）
- 员工在企业微信里开了「仅在企业微信中接收消息」，微信端就收不到——要关掉

### 4. 消息长什么样

```
【守护星】老人较长时间未活动且未回应问候，建议致电确认。
```

前缀 `【守护星】` 在 `_push_wecom()` 里拼的，改文案只改那一行。

## 三、PushPlus（陌生家庭唯一可行的路）

1. 手机微信打开 <https://www.pushplus.plus>，扫码登录
2. **先实名认证**（`verify.pushplus.plus`），不实名调接口会返回 `code: 905`
3. 在「一对一推送」页面复制 Token
4. `export PUSHPLUS_TOKEN="你的token"`

已知限制（都会返回 HTTP 200，所以代码里校验的是业务码）：

| 情况 | 返回 code |
|---|---|
| 未实名 | 905 |
| token 无效 | 903 |
| 当日超 200 条 | 900 |
| 同内容 1 小时内超过 3 条 | 900 |

最后一条对这套设备不构成问题：**同一次静默只推 1 次**（`max_asks_per_visit=2`，推送锁存）。

## 四、验证通道是否真的通了

不用等老人出事，直接调：

```bash
cd guardian
export WECOM_WEBHOOK="https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key"
python -c "import sys; sys.path.insert(0,'src'); import voice; print(voice.push_family('通道测试，收到请忽略'))"
```

- 返回 `True` → 已经发出去，去看微信有没有收到
- 返回 `False` → 看终端输出的错误：`errcode` 非 0 是 key 错，`HTTP xxx` 是网络问题

## 五、密钥不能进仓库

Webhook 的 key 等于**群钥匙**：谁拿到都能往群里发消息。所以：

- 只从环境变量读（`WECOM_WEBHOOK` / `PUSHPLUS_TOKEN`），代码里写死一律不行
- 不要截图到 PPT 或文档里，不要贴进 issue
- 一旦泄露，最稳的补救是在群里**删掉这个机器人重建**，不用心疼那两分钟

`.gitignore` 已经忽略 `data/_push_failed.jsonl`（失败记录里可能带消息正文），但环境变量本身不在仓库里，天然安全。

## 六、这条链路的真实边界（答辩必须说）

| 能做到 | 做不到 |
|---|---|
| 老人不回应时，微信收到一条消息 | 确认家属**已读**。企业微信只回 `errcode:0`（已受理），没有已读回执 |
| 每次事件只推 1 条，不会刷屏 | 断网时推送失败，只落盘到 `data/_push_failed.jsonl`，**没有自动补发** |
| 两条通道互为备份 | 家属不回消息，设备不知道 |
| 群机器人用于自家 / 课程试点 | **卖给陌生家庭**：机器人进不了外部群，家属必须是企业成员 |

**频率限制（官方原文，2026-11 查）**：

- 群机器人：**每个机器人 20 条/分钟**，官方帮助文档**未公布日上限**
- 微信插件：全员群超过 2000 人时消息不同步
- PushPlus：免费版 200 条/天，同内容 1 小时最多 3 条

对本项目够不够？够。一次静默事件只推 1 条，每天最多 2 次点名回执 + 若干告警，
**日均不到 10 条**。20 条/分钟意味着「同一秒内绝不刷屏」，正好符合「别烦到拔电源」的设计。

> 「当天就知道设备被拔了」这句话的成立前提是：**配了通道、家属每天确实收到一条、且知道每天都该有一条**。断电的设备发不出自己的死讯——这是使用约定，不是设备能力。

## 七、如果以后要双向（可选，本期不做）

三条路，从轻到重：

1. **企业微信机器人 + 关键词回复**：家属在群里回「收到」，另起一个脚本轮询群消息。需要企业微信「会话内容存档」权限，个人注册的企业号拿不到。
2. **微信小程序**：扫码即用、不上架应用商店。三个页面足够（今日回执、告警详情、「我已联系」）。约 2–3 天工作量。
3. **自建服务号 + 模板消息**：需要企业资质和认证费，对本项目太重。

**本期一律不做。** 现在的缺口是「设备还没有真实数据」，不是「家属端不够漂亮」。
